# Consultation archive

Full source material behind the [Values and Principles story](../../index.html#how-these-were-formed)
and the [outcome table](../../index.html#outcome) on this repo's front page: the July 1, 2026
consultation ("Start conference SPII-2") and the draft framework it produced. Published here for
transparency — every file below is exactly what participants produced or received, plus a
converted copy of each for easier viewing (no Word/Excel/PowerPoint required).

Organised in the four stages the material moves through:

## `01-consultation-program/`

What participants received going in.

- `guiding-principles-briefing-2026-06-17.docx` / `.md` — pre-reading, June 17, 2026: the NPOS
  guiding principles and POSI, circulated ahead of the event.
- `programme.docx` / `.md` — the day's run-of-show.
- `handout.pdf` — the one-page reference-model handout.
- `presentation-2026-07-01.pptx` — the opening plenary slides.
- `presentation-2026-07-01.pdf` — a **reconstructed** copy: this environment has no working
  PowerPoint renderer, so this PDF was regenerated from the slides' own text and embedded images
  (one slide per page). It preserves every word and diagram but not the original slide design —
  use the `.pptx` for that.

## `02-consultation-output-raw/`

What the event produced, unedited.

- `mentimeter/results-overview.pdf` — Maurits van der Graaf's write-up of the live poll results.
- `mentimeter/raw-data.xlsx` (+ `__voters.csv`, `__session-1.csv`) — the underlying Mentimeter
  export.
- `mentimeter/current-challenges.xlsx` / `.csv` and `which-infrastructure.xlsx` / `.csv` — two
  poll questions' answers, each already grouped into categories by the organisers.
- `posters/poster-1.jpg` … `poster-8.jpg` — photos of the eight breakout groups' physical
  worksheets (sticky notes on a printed principles/subprinciples/consequences grid).

## `03-consultation-output-processed/`

The organisers' first pass at turning the raw output into something coherent.

- `draft-synopsis.docx` / `.md` — draft principles/subprinciples/consequences table synthesised
  from the breakout groups.
- `other-principles-suggested.xlsx` / `.csv` — suggestions that didn't make the draft synopsis.
- `posters-processed.xlsx` / `.csv` — the eight posters' sticky notes transcribed into a table.

## `04-consultation-outcome-framework/`

The result: `values-and-principles-2026-07-08.docx` / `.md` — version dated July 8, 2026, the
source for the [outcome table](../../index.html#outcome) at the top of this repo's `index.html`.
Three values, five principles, their subprinciples, and numbered actions/enablers/practices.

## Conversions

Every `.docx` was converted to `.md`, every `.xlsx` to `.csv` (one file per non-empty sheet), and
the `.pptx` to `.pdf` as described above — mechanically, to make the content readable without
Word/Excel/PowerPoint. Formatting nuances (merged cells, footnote markers, superscript reference
numbers) may not survive the conversion; the original file is always alongside its converted copy
and is the authoritative version. Nothing else in this folder was edited, corrected, or
translated — typos and all, including a few things participants flagged as unresolved (see the
"what didn't make it in" note in the front-page story).
